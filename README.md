## 🌟 项目简介

受够了市面上难用的 AI 视频生成工具？人工写提示词太累、生成的角色疯狂“变脸”、视频背景到处乱飘、稍有不慎接口就被封……

**Viral Shorts Engine** 正是为了解决这些痛点而生！它不是一个简单的脚本，而是一套完整的 **5 步制片流水线**。你只需要输入一句话，它就能包办从编剧、分镜、定妆、生视频、到配音、加字幕的全套流程，最终在本地渲染出一条高清的 4K 爆款短剧。

### 🔥 核心痛点解决：
1. **告别绞尽脑汁写提示词**：底层自动中翻英，并强制挂载爆款标签。
2. **彻底解决“AI变脸”**：首创“定妆室”生成唯一面部锚点，后续视频无缝挂载。支持**三视图、表情集、比例图**等专业角色设定参考单。
3. **拒绝背景乱飘**：引入 `{@场景}` 黑魔法，强行钉死物理背景坐标，杜绝基因突变。
4. **提示词可视化管理中心 (Prompt Studio)**：告别硬编码！在独立的可视化界面中全面接管 11 个核心编导参数，支持动态变量 `{{占位符}}` 注入，一次修改全局生效。内置模板自动升级机制。
5. **3D 布局预设库**：在 Three.js 3D 编辑器中拖拽桌椅摆放构图，保存为可复用预设。自动生成独立 Flow 资产标签，实现场景布局的精确图生图控制。
6. **一站式文件管理**：项目制管理，音频、视频、图片、脚本全部自动归档，告别“桌面垃圾堆”。

## 🛠️ 技术栈 (Tech Stack)

本项目采用全栈组件化架构，代码逻辑极其严密：

- **核心框架**：`Next.js` (React 19) + `TypeScript`
- **本地数据库**：`Prisma 7` + `SQLite` (原生支持原子化高并发写入，完美替代不可靠的 JSON 存储)
- **实时通信**：纯内存级 `SSE (Server-Sent Events)` 桥接机制，实现 Chrome 插件与 Web 端零延迟数据同步
- **视频渲染**：`Remotion 4.0` (纯代码驱动视频合成，零卡顿回放)
- **3D 引擎**：`Three.js` + `React Three Fiber` (构建 Scene Lab 可视化布局编辑器)
- **AI 大脑接入**：`Vercel AI SDK` (集成 MiniMax、Gemini 等顶级模型)
- **极客级自动化**：`Playwright CDP` (Chrome DevTools Protocol)
  - *独创的“劫持网页流”技术，搭配 Exact-Text 精确文本匹配算法，绕过高昂的 API 费用，直接控制宿主浏览器免密且精准地调用 Nano Banana Pro、Veo 3.1 等顶级生图/视频模型。*
- **视觉界面**：`TailwindCSS`

## 🔄 版本更新历史 (Changelog)

- **v7.0 (当前版本 - UI 架构大换血)**：
  - 🚀 **全局 5 步流水线与智能侧边栏**：告别拥挤的顶部阶段条，引入常驻左侧的边栏导航。正式确立了“剧本室 -> 定妆室 -> 分镜区 -> 渲染室 -> 发布中心”的 5 阶段工作流体系。
  - 📺 **释放屏幕空间 (Drawer -> Full Width)**：彻底移除了因历史遗留导致的“定妆与分镜同屏抽屉挤压”。定妆室如今独占全屏网格布局；分镜区也因此获得了极致的宽屏体验。
  - 🌊 **分镜区瀑布流重塑**：废弃了之前由于拥挤而被迫采用的 4 级内部 Tab（会导致严重的高频点击疲劳）。全新引入“左侧剧本大纲列表 + 右侧单列沉浸式瀑布流”结构，滑动滚轮一气呵成完成分镜制作。
  - ⚛️ **剧本室巨无霸原子化**：将高达 600+ 行的组件安全拆解为“灵感采集、AI 毒舌编剧、场景角色拆分”三大独立原子模块，代码可维护性飙升。
  - 📤 **逻辑解耦与独立发布室**：将发版引流文案和海报多比例导出等杂务从渲染室中剥离至全新的 `PublishRoom`，让渲染室 (NLE) 回归时间轴剪辑与导出的本质。
- **v6.5**：
  - 🎨 **组件内部重构尝试**：曾在这一版本尝试通过内部 4 大核心 Tab（“场景与布局”、“智能提示词”、“首尾帧抽卡”与“视频与配音”）来缓解长列表堆叠问题，但后续发现会导致操作层级过深，遂在 v7.0 进化为双栏瀑布流。
  - 🧍 **3D 站位精细化拆分**：废除了容易混淆的全局 3D 布局，现在首帧和尾帧拥有各自独立的专属 3D 布局编辑入口（嵌入在抽卡界面），从底层逻辑上消除了画面运动落点的歧义。
  - 🤖 **资产全自动注入**：针对 3D 布局图片保存繁琐的问题，开发了革命性的自动化流程。点击前端按钮，后台将通过 Playwright 在底层浏览器环境伪造系统剪贴板（Clipboard Paste）事件，瞬间将 3D 图片直接注入到 Google Flow 聊天框并自动发送，彻底省略了手工截屏上传。
- **v6.4**：
  - 💾 **本地数据库重构**：全面引入 Prisma 7 + SQLite，实现了底层读写的原子化 PATCH 增量更新。彻底告别因高并发读写 `project.json` 导致的文件损坏问题。支持旧版本项目的无感热迁移！
  - ⚡ **零延迟推送**：废除了低效的硬盘轮询机制，采用纯内存级 Server-Sent Events (SSE) 通信。Chrome 插件推送的素材将在**毫秒级**同步至网页端！
  - 🎯 **狙击级自动填充**：重写了底层自动化脚本（Playwright）。针对 Google Flow 的模糊搜索 Bug，增加了精确文本（exact text）强匹配算法，100% 杜绝自动化抽卡时“选错素材”的致命事故。
  - 🔙 **时光倒流体验**：移除了“场景锁定”限制。现在你可以在任意幕之间自由穿梭修改，后续镜头将自动继承前一镜的最新修改。
- **v6.3**：重构 API 网关透传机制 (Pass-through Meta)，实现无状态高并发素材落盘。
- **v6.2**：Chrome 扩展全面升级为 Type-only Import 的 TypeScript 编译架构。
- **v6.1**：全域状态解耦（重构上帝 Hook）与 `assetUrl` 资源全生命周期管控标准化。
- **v5.0**：首创 3D 定制化画板（Scene Lab）与动态 Prompt 预设库（Prompt Studio）。
